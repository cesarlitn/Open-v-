================================================================================
 OPEN V - DEVELOPER HANDOFF (current as of v6.8.0)
================================================================================
Local, single-user web app: generate/manage anime-game-RPG character images via
a local ComfyUI. UI in English; this document in Spanish.

--------------------------------------------------------------------------------
 1. STACK
--------------------------------------------------------------------------------
  Frontend : React 18 + Vite           (puerto 5173)
  Backend  : Node + Express            (puerto 3001)
  DB       : SQLite via sql.js         (database/studio.db)
  Externos : ComfyUI (generar/upscale/tag) y Ollama (LLM local para tags)
  Visual   : CLIP en el navegador (transformers.js + WebGPU)

--------------------------------------------------------------------------------
 2. ARQUITECTURA (rutas -> controladores -> servicios -> db)
--------------------------------------------------------------------------------
  backend/src/
    config.js            UNICA fuente de URLs/puertos (lee de .env con defaults)
    index.js             arranque: carga .env -> db.init -> migraciones -> rutas
    routes/api.js        define todos los endpoints REST
    database/db.js       sql.js; migraciones de esquema no destructivas
    services/
      comfyui.js         cola, websocket de progreso, generar, tag, upscale
      localllm.js        proveedores LLM local + cloud (URLs en config.js)
      embeddings.js      helpers de vector (base64 + coseno) para similitud
      migrate.js         re-ancla rutas, reubica thumbs, reconstruye historial
    controllers/         history, embed (visual), settings, poses, upscale,
                         publish, tag, generate, llm, loras, workflows
  frontend/src/
    pages/   Home (generar), DesignsPage (Models), Landing
    hooks/   useHistory (paginacion+modos), useModels, useLoras
    services/ api.js, clip.js (CLIP navegador), imageIndexer.js
    components/ ConfigPanel, PromptPanel, HistoryGallery, DetailView,
               SettingsPanel, PosesTab, Replicate/FindReplace/Upscale Tab, ...
    styles/global.css   tema "Midnight & Champagne" (claro/oscuro por tokens)

--------------------------------------------------------------------------------
 3. CONVENCIONES
--------------------------------------------------------------------------------
  - Nada hardcodeado: toda URL/puerto en config.js (backend) o VITE_* (frontend).
  - Credenciales de usuario en Settings -> DB, nunca en codigo ni .env.
  - DRY: la logica de indexado visual vive en services/imageIndexer.js y la usan
    tanto el arranque automatico como la generacion.
  - Cada archivo lleva cabecera con su proposito; funciones/endpoints complejos
    estan comentados explicando que hacen, que reciben y por que.
  - Migraciones SIEMPRE no destructivas (ADD COLUMN IF NOT EXISTS).

--------------------------------------------------------------------------------
 4. BUSQUEDA VISUAL (find similar)
--------------------------------------------------------------------------------
  - Embedding de imagen = CLIP en el NAVEGADOR (no toca la VRAM de ComfyUI).
  - Se guarda Float32->base64 en la misma fila (img_embed / img_embed_model).
  - Ranking por POSE primero (tags del prompt) + CLIP como desempate.
  - Indexado AUTOMATICO: al arrancar (migracion) y tras cada generacion.

--------------------------------------------------------------------------------
 5. ESCALA
--------------------------------------------------------------------------------
  - Coseno en memoria: ok para decenas de miles de imagenes.
  - A cientos de miles/millones: base de vectores (pgvector/Chroma) + ANN.
  - Multiusuario/nube: requeriria auth y otro almacenamiento.

Ver README.txt (arranque), config/.env.example (variables).
